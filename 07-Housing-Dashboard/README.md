# 07 - Amsterdam Housing Dashboard

## Overview
This project is a lightweight, full-stack web dashboard built with Flask and Python. It dynamically serves database records generated by an automated housing bot, providing a clean, browser-based interface to track newly listed properties in Amsterdam.

## Tech Stack
* **Backend:** Python, Flask
* **Database:** SQLite3, Pandas
* **Frontend:** HTML, Jinja2 Templating

## Key Features
* **Dynamic Data Rendering:** Uses Jinja2 to seamlessly inject live SQLite database records directly into the HTML frontend.
* **Database Integration:** Leverages Pandas to efficiently query the `seen_houses` table and structure the payload for web display.
* **Safe Fallback Logic:** Includes `try/except` error handling to render an empty state if the database is missing or unreadable, actively preventing complete server crashes.
* **Secure Architecture:** The public dashboard remains strictly isolated from the backend scraping script, ensuring API tokens and personal Telegram webhooks remain completely private.

## How to Run Locally
1. Clone this repository to your local machine.
2. Ensure Python 3, Flask, and Pandas are installed (`pip install flask pandas`).
3. Run `python3 app.py` in your terminal.
4. Navigate to `http://127.0.0.1:5000` in your web browser to view the active dashboard.

*Note: The local SQLite database file (`amsterdam_houses.db`) is intentionally excluded from this repository. Running the app locally will trigger the fallback logic and smoothly default to a safe state of 0 tracked properties.*
