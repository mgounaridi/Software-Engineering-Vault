# Student Management System (OOP Fundamentals)

A Java application built to demonstrate core Object-Oriented Programming principles. The system models student data and performs automated academic calculations over a dataset.

**Core Concepts Demonstrated**
* **Encapsulation:** Designed a `Student` class with private attributes (name, grade, major, year) accessed securely via getters, setters, and a parameterized constructor.
* **Collections Framework:** Managed object datasets dynamically using Java's `ArrayList`.
* **Algorithmic Iteration:** Implemented enhanced `for` loops to parse object data, dynamically calculating class averages, identifying maximum/minimum grades, and evaluating Boolean pass/fail conditions based on a predefined threshold.
