# Responsive Art History Gallery (Front-End UI)

A visually engaging, static web interface dedicated to the history of painting. Built entirely with native web technologies to demonstrate front-end structural design and styling principles.

**Core Technologies & Concepts**
* **Semantic HTML5:** Structured content routing using modern tags (`<header>`, `<nav>`, `<main>`), and implemented `<figure>` and `<figcaption>` elements for accessible, screen-reader-friendly image displays.
* **CSS3 Animations:** Designed custom `@keyframes` (`fadeInUp`) to create smooth, professional fade-in transitions that enhance the user experience without relying on external JavaScript libraries.
* **Modern Layouts:** Utilized CSS Flexbox for dynamic navigation alignment and applied sticky positioning (`position: sticky; top: 0;`) to ensure the header remains accessible during scroll.
* **UI/UX Design:** Implemented a cohesive color palette, responsive container max-widths, and layered box-shadows to create a polished, museum-like aesthetic.
